## 三、三条容易踩的限制，第二条最容易被忽略

**1. 住宅 IP 不开放 80 和 443 端口。**

官网在住宅 IP 产品的描述里写得很直白：

> Due to IP risk control reasons, residential IP products do not open ports 80 & 443.（因 IP 风控原因，住宅 IP 产品不开放 80 和 443 端口。）

这意味着你不能在这台机器上直接跑网站。想拿家宽 IP 建站、挂独立站、做落地页的，看到这条就该关掉页面了，转去买同价位的原生 IP 建站机。这条限制在家宽 VPS 里算常见做法，但大多数“优惠码合集”不会提。

**2. IRVINE-PRO 系列要白名单或端口转发才能连。**

官网原文的意思是：该系列拒绝一切外部探测和扫描以保证稳定性，没有中转 IP，不配置访问白名单或端口转发，服务完全不可达。只有受信任的 IP 能连进去，第三方无法扫描。

这是把双刃剑。安全性确实上去了，但你的本地公网 IP 一变（家宽动态 IP、换网络、出差），就得回后台改白名单。做自动化脚本、多设备切换、团队协作的场景，这个流程会烦。LAX 四档没有这条限制。

**3. 退款只退到网站余额，而且注册要手机号。**

官网把 IRVINE-PRO 的退款条款单独写了出来：该产品的退款只对网站余额有效，不原路退回支付渠道。也就是说买错了想拿回现金，走不通，钱只能留在账户里继续消费。LAX 系列官网没写这条，具体条款下单前问客服确认。

另一个门槛来自第三方测评：注册环节需要手机号验证，+86 号码收不到验证码。这一条没在官网页面上看到说明，属于测评方的实际体验记录，国内买家最好先确认自己能完成验证再谈下单。

## 四、家宽 VPS 怎么验货，下单当天做完

家宽 VPS 的钱主要花在 IP 属性上，所以验货就验 IP。三步，半小时能跑完。

**第一步，查类型。** 把机器 IP 丢进 ipinfo.io，看 `type` 字段是不是 `isp`，ASN 和 Company 显示的应该是运营商名字（Cox、Wave Broadband 这类），不能是 Hosting 或 Datacenter。显示 Hosting 就说明你买到的是机房 IP 套壳，直接走退款流程。

**第二步，查风控分。** 同一个 IP 拿去 scamalytics.com 查，分数越低越好。这一步查的是这个 IP 段有没有被前人用滥，同一段 IP 被注册过多少账号、有没有进过黑名单，分数会体现出来。

**第三步，拿目标平台实测。** 你要跑 TikTok 就用它注册一次，要 ChatGPT 就登录一次，要 Netflix 就播一集。IP 库显示干净不代表平台风控认，平台自己有独立判断。

**为什么不能只看商品页？** 家宽圈子里的通行话术是“支持 TikTok、ChatGPT、Netflix”，这句话描述的是线路能连通，跟 IP 是不是 ISP 属性是两件事。有商家自己都会在活动推文里提醒：部分套餐标注支持这些平台，但 IP 不保证 ISP 属性。买之前把这两件事分开看，就不会被文案带走。

验货的时间窗越短，越要当天做完。退款窗口按天算，不是按小时算，机器开通后第一件事就是跑上面三步，别等到第三天才想起来测。
